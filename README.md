# toeic-vocab-daily
매일 TOEIC 900 수준 영어 단어 10개를 학습하는 웹앱입니다.

## 주요 기능

- 매일 단어 10개 표시
- 영어 단어, 한국어 뜻, 영어 예문, 한국어 해석 제공
- 외웠음 체크박스
- 체크 상태 저장
- 오늘 학습 완료 기능

## 파일 구조

- `index.html`: 화면 구조
- `style.css`: 디자인
- `app.js`: 앱 동작
- `words.json`: 단어 데이터

## 데이터 흐름

1. `words.json`에서 단어 데이터를 불러옵니다.
2. `app.js`가 오늘 날짜에 맞는 단어 10개를 선택합니다.
3. 선택된 단어를 화면에 표시합니다.
4. 사용자가 체크박스를 누르면 브라우저에 저장됩니다.
5. 새로고침해도 체크 상태가 유지됩니다.

## 앞으로 추가할 기능

- 이전 날짜 단어 보기
- 복습 단어 기능
- 퀴즈 기능
- 완료율 통계
